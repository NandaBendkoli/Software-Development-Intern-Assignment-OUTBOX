# ReachInbox - Email Scheduling & Campaign Management System

A full-stack email scheduling and campaign management application built as part of the Software Development Intern Assignment.

The application allows users to authenticate using Google OAuth, configure email senders, create campaigns, upload recipients through CSV, schedule emails, process emails asynchronously using BullMQ and Redis, and monitor campaign/email delivery status from the dashboard.
